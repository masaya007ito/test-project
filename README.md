## Stickers Feature

An interactive sticker canvas where you can:

- Pick a sticker from the palette (stars, hearts, rockets, and more)
- Click anywhere on the canvas to place it
- Drag placed stickers to reposition them
- Adjust sticker size with the slider
- Clear the canvas to start fresh

Open `index.html` in a browser to try it out.
